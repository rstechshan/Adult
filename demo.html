🎨 Shanaka Technic Theme Demo

About This Demo

This is a demonstration page for the Shanaka Technic Blogger theme. The actual theme is contained in theme.xml and should be uploaded to Blogger.

Key Features:

  • ✨ Modern glassmorphism UI with backdrop blur effects
  • 🎨 Dark/Light mode toggle with localStorage persistence
  • 📱 Fully responsive design (320px to 1366px+)
  • 🎬 YouTube Data API v3 integration
  • 📊 Live subscriber count with animated counters
  • 🎪 Carousel/slider components
  • ♿ WCAG AA accessibility compliant
  • 🚀 Performance optimized (lazy loading, inline critical CSS)
  • 🔍 SEO ready with structured data

Installation

  1. Download theme.xml from this repository
  2. Go to your Blogger dashboard
  3. Navigate to Theme section
  4. Click the dropdown menu (⋮) next to "Customize"
  5. Select Restore → Upload
  6. Choose the theme.xml file
  7. Click Upload and confirm

For detailed instructions, see INSTALLATION.md

Configuration

After uploading the theme, you'll need to configure:

  • YouTube API Key - Get from Google Cloud Console
  • YouTube Channel ID - Find in YouTube Studio settings
  • Social Media Links - Update in the theme HTML
  • Colors - Customize CSS variables
  • Fonts - Change Google Fonts links

See CUSTOMIZATION.md for full customization guide
